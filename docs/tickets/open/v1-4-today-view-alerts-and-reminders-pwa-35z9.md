## The ask

- Today view: today's Time Block (current row), tasks due/overdue
  (`meta-notes tasks --overdue --due --json`), the day's agenda when
  calendar is set up.
- Alerts and reminders: browser notifications for timed tasks
  (`⏰`/time of day) and the next Time Block row, while a tab is open;
  snooze. (Push to a closed phone is later, with the phone bridge.)
- PWA: manifest, icons, installable on the phone's home screen; works
  over the phone host binding.
