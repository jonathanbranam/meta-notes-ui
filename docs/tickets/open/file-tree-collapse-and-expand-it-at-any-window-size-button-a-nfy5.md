## The ask

From the human, via the notes advisor (message m-0455 to the aide), 2026-10-10 10:28 ET, verbatim:

"The file tree on the left collapses when the screen is too small, but I also want to be able to control that: expand and collapse it myself in a browser, even when my window is large. It should be adjustable and draggable as well. I should be able to pin it with some left-facing arrows, and then it disappears. There's a button to expand it again, and that's it."

## The ask, in parts (the advisor's reading)

1. A control to collapse and expand the file tree at any window size, not only when the screen is small.
2. The tree's width is adjustable by dragging its edge.
3. A left-facing arrows control (`<<`) collapses the tree; a button brings it back.
