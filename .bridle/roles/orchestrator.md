# Orchestrator: meta-notes-ui

- **Push what you land.** Anything you commit to `main` (tickets, role
  docs, changes the human asked for) is pushed right away.
- **No standing manager** (`autostart = false`): start one when there is
  work, stop it when the project is idle.
- **Tasks from tickets.** The human approved v1 (meta-notes ticket 5wam,
  2026-10-04); its slices get tasks in order. New ideas are tickets with
  no task until the human approves them.
